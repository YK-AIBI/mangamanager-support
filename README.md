# まんが管理（MangaManager）サポート

「まんが管理」をご利用いただきありがとうございます。本ページはアプリのサポート窓口です。

## アプリについて
持っている漫画を巻ごとに記録して、**重複購入や買い逃しを防ぐ**蔵書管理アプリです。
書店で「何巻まで持っているか」がひと目で分かります。

- タイトル検索で完結／連載状況・全巻数・表紙を自動取得
- 巻ごとの所持チェック（飛ばし買い＝非連続にも対応）
- コンプリート判定、未所持巻の一覧表示
- データは端末内に保存（検索時のみ通信）

## よくある質問

**Q. 検索しても作品が出てきません。**
A. データベースに未収録・表記ゆれの場合があります。追加画面の「手動で追加」からタイトル・巻数を入力して登録できます。

**Q. データは他の端末と同期されますか？**
A. 現在はお使いの端末内にのみ保存されます。

**Q. オフラインで使えますか？**
A. 登録済みデータの閲覧・チェックはオフラインで可能です。作品検索時のみ通信が必要です。

## プライバシー
本アプリは、蔵書データを端末内に保存します。個人を特定する情報の収集は行いません。
（広告表示に関する情報の取り扱いは、アプリ内の設定・App Store のプライバシー表示をご確認ください。）
